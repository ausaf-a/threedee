# Windows XP 3D Adventure

A nostalgic 3D game with a Windows XP theme built using Three.js. Experience the iconic Bliss landscape in an interactive 3D environment!

## Features

- **Windows XP Aesthetic**: Complete with XP-style taskbar, windows, and that iconic blue
- **Bliss-Inspired World**: Explore rolling green hills reminiscent of the famous XP wallpaper
- **Simple Gameplay**: Collect glowing XP gems and rack up your score
- **Cross-Platform**: Runs on iOS, macOS, Linux, and Windows - anywhere with a modern web browser
- **Smooth Controls**: WASD movement + mouse camera controls

## How to Play

1. Open `index.html` in any modern web browser
2. Use **WASD** keys to move your Windows logo character around
3. **Click and drag** with your mouse to rotate the camera
4. Collect the **blue XP gems** to increase your score
5. Explore the nostalgic Bliss landscape!

## Tech Stack

- **Three.js** - Minimal, cross-platform 3D library
- **Pure JavaScript** - No build process required
- **HTML/CSS** - For the XP-themed UI

## Why This Stack?

This project uses **Three.js** because it's:
- The simplest way to create cross-platform 3D experiences
- Works on all platforms through a web browser (iOS, macOS, Linux, Windows)
- Requires minimal code - just ~400 lines for the entire game
- No compilation or build process needed
- Can be easily packaged as a native app if desired using Electron or Capacitor

## Local Development

Simply open `index.html` in your browser. No build process required!

For a local server:
```bash
python -m http.server 8000
# or
npx serve
```
